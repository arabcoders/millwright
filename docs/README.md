# Millwright documentation

## Getting started
- [project overview](../README.md): Basic introduction to Millwright.

- [Using Millwright](usage.md): Add a library, choose a flow, and try your first conversion.

- [Authentication](authentication.md): Set up OIDC, change your password, or recover access.
- [Incoming webhooks](webhooks.md): Let Sonarr, Radarr, or another app tell Millwright about changed files.
- [Recovery and backups](recovery.md): Restore an original, free workspace space, and back up your instance.
- [Security](../SECURITY.md): Deployment advice and private vulnerability reports.

- [Plugin authoring](plugins.md): Write your own processing steps.
- [Live API updates](events.md): Receive job progress and file, library, and node updates.
- [Contributing](../CONTRIBUTING.md): Propose a change and set up a development checkout.
- [Development guide](development.md): Build containers, test OIDC, and change the database schema.
